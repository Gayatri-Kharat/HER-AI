Prompt 1 — The Foundation
Build the complete Life Operating System
Build a complete Life Operating System for women called "HER-AI" with 8 modules: Productivity (energy-based task management), Smart Scheduler (cycle-aware planning), Learning (AI instructor with courses), Home Life (grocery, meals, geo-reminders), Finance (budgeting & tracking), Leadership (email rewriting, negotiation), Branding (LinkedIn, pitches), and Wellness (mood, sleep, cycle tracking). Use vanilla HTML/CSS/JS, no frameworks. Include a landing page and a dashboard app. Use Groq LLM with rule-based fallback. Create these files: 1. index.html — Landing page with full-screen hero (plum-to-rose gradient, floating particles), 8 theme cards grid, stats strip, cycle awareness section with animated ring, 3 feature deep-dives, navbar with mobile hamburger, scroll animations using IntersectionObserver. 2. app.html — Dashboard app with fixed sidebar (240px, dark plum), sticky topbar with cycle/energy indicators, and these pages: • Dashboard: stat cards, schedule timeline, AI suggestions, quick actions, mood mini tracker • Productivity: energy selector (High/Med/Low), task list with add/delete/complete, priority badges • Smart Scheduler: weekly view, auto-schedule by priority + energy, workload bar • Learning: 4 course cards with progress bars, AI instructor chat per course • Home Life: tabs for Groceries (CRUD list), Meals (weekly planner), Geo-Reminders (location-based alerts) • Finance: budget setting, spending by category with progress bars, expense tracking • Leadership: AI email rewriter, negotiation script generator, meeting prep • Wellness: mood logger (emoji buttons), sleep tracker, cycle tracker with phase calculation • AI Chat: conversational chat with user/AI bubbles, typing indicator • Settings: API key, name, theme toggle 3. app.css — Full design system with light/dark themes using CSS variables. Colors: plum #6B2D5B, rose #E8526F, gold #D4A853, mint #7ECEC1. Fonts: Playfair Display, DM Sans, Syne. 4. app.js + module files — State management with localStorage, Router for page switching, all module logic split into separate files (app.state.js, app.router.js, app.dashboard.js, app.productivity.js, app.scheduler.js, app.learning.js, app.home.js, app.finance.js, app.leadership.js, app.wellness.js, app.branding.js, app.ui.js, app.init.js, app.settings.js, app.ai-chat.js). 5. app.ai-engine.js — Hybrid AI: Groq API (LLaMA 3.3 70B) with rule-based fallback. chat() for keyword matching, chatLLM() for real AI responses. 6. config.example.js — Example API key config. 7. architecture.html — Dark-themed tech architecture page showing system layers.

Prompt 2 — Intelligence Layer
Make the AI contextual and personalized
Enhance the HER-AI application with these improvements: 1. RESPONSIVE DESIGN — Add comprehensive responsive CSS for all screen sizes. 3 breakpoints: 1024px (tablet), 768px (mobile: sidebar off-screen, grids single-column, chat adapts), 480px (compact everything, hide greeting, shrink badges). Sidebar should have an overlay that closes it when tapped. 2. ENERGY-BASED TASK UI — When user selects energy level in Productivity: High energy = high-priority tasks get green border + "⚡ Do now" badge, low-priority get dimmed + "💤 Defer". Medium energy = medium tasks highlighted. Low energy = low tasks recommended. Both Productivity and Dashboard update immediately. 3. REAL GEO-REMINDERS — Replace simulated geo with real browser geolocation. Use navigator.geolocation.getCurrentPosition() + fetch to https://nominatim.openstreetmap.org/reverse for reverse geocoding. Match nearby locations against stored geo-reminder categories. Add snooze to prevent re-triggering. Check every 3 minutes. 4. PERSONALIZED AI CHAT — In chatLLM(), build rich context by checking message keywords and injecting relevant live data: tasks + priorities for task queries, budget + expenses for finance queries, moods + sleep for wellness queries, schedule for planning queries, cycle phase for health queries. The LLM should answer based on ACTUAL user data, not generic advice. 5. AI ERROR HANDLING — If chatLLM fails, show clear error: "Could not reach AI service. Check your API key in Settings." Never silently fall back. 6. CSS SAFETY — Add img, video, svg max-width:100%. Use minmax(min(Xpx, 100%), 1fr) in all grids. overflow-x: hidden on html/body. word-break: break-word on long text.
Output: Personalized AI responses using real data, energy-adaptive task UI with visual indicators, real GPS-based geo-reminders, fully responsive on all screens.
Live Data Context Energy UI Real Geolocation Responsive Smart Fallbacks

Step 4 🔑 Add Groq API Key

Get a free API key from Groq in 30 seconds. Paste it in Settings. The AI brain comes alive.

1. Go to console.groq.com → Sign up for free

2. Click "API Keys" → Create a new key → Copy it

3. In the HER-AI app, go to Settings (gear icon) → Paste your key
